# 🎬 Cinema in Busan

> 영화관 및 영화 기반 상영 스케줄 조회 웹 페이지

---

## 📌 의의

기존 영화 예매 서비스는 각 영화관의 웹사이트에서 따로 상영 일정을 확인해야 했지만, <br>
이 페이지는 영화관 3사의 상영일정을 한 번에 제공합니다.

> 특정 영화를 관람하고 싶은 사용자가,
> "오늘 이 영화는 어디에서 상영하지?" 라는 관점으로 탐색할 수 있도록 설계된 UX <br>
> 영화관별로도 상영일정 확인 가능
